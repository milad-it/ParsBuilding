# ParsBuilding (سامانه مدیریت ساختمان پارس)

یک وب‌اپلیکیشن جامع، مدرن، آفلاین و ریسپانسیو (PWA) برای مدیریت هزینه‌ها، شارژ واحدها، گزارش‌گیری مالی و مدیریت ساکنین مجتمع‌های مسکونی و تجاری.

## ویژگی‌ها (Features)
- 🏢 **مدیریت واحدها و ساکنین:** ثبت اطلاعات واحدها، مالکان، مستاجران و وضعیت سکونت
- 💰 **محاسبه و مدیریت شارژ:** محاسبه خودکار شارژ ثابت و متغیر بر اساس متراژ، نفرات یا سهم مساوی
- 📊 **ثبت هزینه‌ها و قبوض:** دسته‌بندی و پیگیری فاکتورها، تعمیرات و قبوض عمومی ساختمان
- 📈 **گزارش‌های جامع مالی:** صدور تراز مالی، صورت‌حساب اختصاصی هر واحد و پیش‌نمایش چاپی بهینه‌شده
- 💬 **ارسال و اشتراک‌گذاری صورت‌حساب:** ارسال مستقیم صورت‌حساب واحدها به همراه ریزمحاسبات از طریق پیامک، ایتا، بله، واتساپ یا کپی در کلیپ‌بورد
- 🌐 **کارکرد کاملاً آفلاین (Offline Ready):** بدون هیچ‌گونه وابستگی به CDNهای خارجی با فونت محلی وزیرمتن و استایل‌های ذخیره‌شده
- 📲 **اپلیکیشن تحت وب پیش‌رونده (PWA):** امکان نصب مستقیم روی گوشی‌های هوشمند (اندروید و iOS) و دسکتاپ با Service Worker و آیکون‌های اختصاصی
- 💾 **ذخیره‌سازی امن دوگانه (IndexedDB + LocalStorage):** حذف محدودیت حجم LocalStorage و مقاومت در برابر پاک شدن کش مرورگر

## ساختار پروژه (Project Structure)
```
ParsBuilding/
├── index.html              # صفحه اصلی و ساختار رابط کاربری (UI)
├── manifest.json           # مانیفست اپلیکیشن وب پیش‌رونده (PWA)
├── sw.js                   # سرویس‌ورکر جهت کش آفلاین دارایی‌ها
├── icons/                  # آیکون‌های اپلیکیشن در سایزهای استاندارد
│   ├── icon-192.png
│   ├── icon-512.png
│   └── icon.svg
├── css/
│   ├── styles.css          # استایل‌های اختصاصی و قالب چاپ
│   └── fonts/              # فونت‌های محلی وزیرمتن (بدون نیاز به اینترنت)
│       ├── vazirmatn.css
│       └── *.woff2
├── js/
│   ├── vendor/             # کتابخانه‌های محلی
│   │   └── tailwind.js     # موتور Tailwind CSS آفلاین
│   ├── app.js              # نقطه ورود، روتینگ و مدیریت تاریخچه مرورگر
│   ├── idb.js              # لایه ذخیره‌سازی نامحدود IndexedDB
│   ├── state.js            # مدیریت وضعیت، Undo/Redo و پشتیبان‌گیری
│   ├── logic.js            # قوانین و منطق محاسباتی شارژ و تسویه
│   ├── ui.js               # مدیریت رویدادها، رندر و اشتراک‌گذاری صورت‌حساب
│   ├── reports.js          # ماژول گزارش‌های بدهکاران و تراز
│   └── utils.js            # توابع کمکی، فرمت اعداد و تاریخ شمسی
└── README.md               # مستندات پروژه
```

## نحوه اجرا (How to Run)
این پروژه کاملاً مستقل از سرور (Client-Side) بوده و به صورت ۱۰۰٪ آفلاین قابل استفاده است:
1. فایل `index.html` را مستقیماً در هر مرورگری (Chrome, Edge, Safari, Firefox) باز کنید.
2. برای نصب به عنوان اپلیکیشن (PWA)، در نوار آدرس مرورگر روی گزینه **Install** یا در موبایل روی **Add to Home screen** بزنید.
