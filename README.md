# ParsBuilding (سامانه مدیریت ساختمان پارس)

یک وب‌اپلیکیشن جامع، مدرن و ریسپانسیو برای مدیریت هزینه‌ها، شارژ واحدها، گزارش‌گیری مالی و مدیریت ساکنین مجتمع مسکونی و تجاری.

## ویژگی‌ها (Features)
- 🏢 **مدیریت واحدها و ساکنین:** ثبت اطلاعات واحدها، مالکان، مستاجران و وضعیت سکونت
- 💰 **محاسبه و مدیریت شارژ:** محاسبه خودکار شارژ ثابت و متغیر بر اساس متراژ، نفرات یا سهم مساوی
- 📊 **ثبت هزینه‌ها و قبوض:** دسته‌بندی و پیگیری فاکتورها، تعمیرات و قبوض عمومی ساختمان
- 📈 **گزارش‌های جامع مالی:** صدور تراز مالی، صورت‌حساب اختصاصی هر واحد و پیش‌نمایش چاپی
- 📱 **طراحی مدرن و ریسپانسیو:** بهینه‌سازی کامل برای موبایل، تبلت و دسکتاپ با استفاده از فونت استاندارد وزیرمتن و Tailwind CSS

## ساختار پروژه (Project Structure)
```
ParsBuilding/
├── index.html          # صفحه اصلی و ساختار رابط کاربری (UI)
├── css/
│   └── styles.css      # استایل‌های اختصاصی و سفارشی‌سازی‌های ظاهری
├── js/
│   ├── app.js          # نقطه ورود و راه‌اندازی اپلیکیشن
│   ├── ui.js           # مدیریت رویدادها، رندر و تعاملات کاربری
│   ├── logic.js        # منطق محاسباتی شارژ و قوانین مالی
│   ├── state.js        # مدیریت وضعیت و ذخیره‌سازی محلی (LocalStorage)
│   ├── reports.js      # ماژول صدور و تحلیل گزارش‌ها
│   └── utils.js        # توابع کمکی، فرمت اعداد و تاریخ شمسی
└── README.md           # مستندات پروژه
```

## نحوه اجرا (How to Run)
این پروژه یک وب‌اپلیکیشن مستقل مبتنی بر Client-Side (Vanilla JS + HTML5 + CSS3) است و نیاز به سرور یا پیش‌نیاز خاصی برای اجرا ندارد:
1. فایل `index.html` را مستقیماً در هر مرورگری (Chrome, Firefox, Edge, Safari) باز کنید.
2. یا با استفاده از اکستنشن **Live Server** در VS Code / Antigravity آن را اجرا نمایید.
